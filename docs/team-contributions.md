# 팀이 함께 반영한 기능

2026년 11월 23일 팀이 병합한 변경 요청(PR) 중 플레이 과정에 영향을 준 작업을 정리했다. 번호는 당시 개발 기록의 변경 단위다. 각 행의 링크는 공개판에서 구현과 검증 코드를 직접 확인할 수 있는 위치다.

| 변경 기록 | 반영한 내용 | 공개 구현 |
| --- | --- | --- |
| #1 · 캠퍼스 장소 | 경북대 대구캠퍼스를 참고해 장소 배경을 다듬고, IT대학 융복합관(IT5), IT4호관과 IT4 강의실을 추가했다. | [지도·출입구 정의](../public/campus/scenes.js) · [장면 검사](../test/scenes.test.mjs) |
| #2 · 공부 계획 | 과목마다 공부 시간을 관리하는 타이머와 할 일을 추가했다. | [공부 화면](../public/campus/study.js) · [공부 UI 검사](../test/study-ui.test.mjs) |
| #3 · 옷장과 수업 | 옷장을 과잠룩·시험기간룩·꾸꾸꾸룩으로 나누고 IT5에 수업 중 상태를 추가했다. | [옷장 분류](../public/campus/wardrobe.js) · [캠퍼스 인터랙션](../public/campus/app.js) |
| #7 · 모바일 UI | 모바일 캠퍼스 조작의 표현을 통일하고 옷장·상점의 사용 흐름을 개선했다. | [모바일 UI 검사](../online/check-mobile-ui.mjs) |
| #8 · 화면 회전 | 화면을 돌린 직후 지도에서 누른 위치와 벤치의 터치 좌표가 일치하도록 맞췄다. | [웹판 지도와 입력 처리](../online/main.js) · [브라우저 검사](../online/check-plaza.mjs) |
| #9 · 피팅룸 | 도트 피팅룸을 추가하고 모바일 옷장·상점의 선택 버튼을 개선했다. | [옷장 UI](../public/campus/wardrobe-ui.js) · [피팅룸 배경](../design/stage1/assets/panels/fitting-room.png) |
| #10 · 버튼 | 도트 버튼 모서리의 윤곽을 부드럽게 조정했다. | [공통 버튼 스킨](../design/stage1/assets/interface.css) |
| #12 · 행사 광장 | LAN 메인 광장 정원을 100명으로 확장했다. 인원 초과·전원 채팅 수신·퇴장 후 재입장을 모의 시험에 넣었다. | [방 서버](../src/server.mjs) · [100명 시험](../scripts/load-event-plaza.mjs) · [측정 결과](network-research.md) |
| #13 · 캠퍼스 입력과 착석 | 한글 입력 상태에서 방향키·WASD 이동을 점검하고, 좌석은 서버가 착석을 확인한 뒤 표시하도록 조정했다. 휴대폰 도서관의 이동·좌석 버튼 간격도 다듬었다. | [입력 회귀 테스트](../test/campus-input.test.mjs) · [실제 브라우저 조작 검사](../online/check-campus-input.mjs) |
| #14 · 배경 사전 로딩 | 목적지 그림을 내려받아 디코딩할 동안 출발지 화면을 유지한다. 준비가 끝나면 장소 이름·그림·캐릭터가 함께 바뀐다. 실패한 그림은 다시 받을 수 있다. | [이미지 준비 처리](../public/campus/scene-images.js) · [느린 응답 및 재시도 검사](../scripts/check-scene-loading.mjs) |
| #15 · 재입장과 공부 기록 | LAN, 웹 직결, HTTPS 방에서 참가자 교체 뒤 남은 사람의 이동·채팅과 공부 기록 흐름을 검사했다. | [통합 브라우저 검사](../online/check-campus-journeys.mjs) |
| #16 · 자율 참여 모임 | 학과·동아리·스터디 모임을 만들고 초대를 받은 사람이 내용을 확인한 뒤 참여하도록 했다. | [모임 화면](../online/meetup-ui.js) · [모임 검사](../online/check-meetup.mjs) |
| #17 · 홈 화면 설치 | 공개 웹 광장을 홈 화면에서 열고, 오프라인 이후 원래 주소로 다시 접속할 수 있도록 했다. | [설치 안내](web-entry.md) · [설치 검사](../online/check-install.mjs) |
| #18 · 팝업 구분 | 창에 따라 제목 색을 구분하고 화면 크기별 스크롤바와 조작을 확인했다. | [팝업 화면 검사](../online/check-window-themes.mjs) |
| #19 · 옷장 복원 | 웹에서 파일을 옮긴 뒤에도 닉네임과 착용 코디가 공부 기록·구매 내역과 함께 복원되도록 했다. | [공부 저장소](../online/study-notebook.js) · [백업 회귀 검사](../test/web-study-notebook.test.mjs) |
| #20 · 수업 중 표시 | IT5 앞마당에서 선택한 수업 상태를 웹의 두 연결 방식으로 알리고, 늦게 들어온 친구의 이름표와 명단에도 반영했다. | [수업 상태 브라우저 검사](../online/check-class.mjs) |
| #22 · 팝업 제목 | 창 제목의 테두리를 없애고 옅은 종이색이 가장자리까지 이어지도록 다듬었다. 작은 화면과 데스크톱에서 글자 대비·스크롤·키보드 포커스도 함께 확인했다. | [공통 화면 스타일](../design/stage1/assets/interface.css) · [팝업 검사](../online/check-window-themes.mjs) |
| #23 · 웹 강의실 좌석 | IT4 강의실의 책상 8개와 의자 24개를 웹판에 그리고, LAN판의 좌석 위치를 재사용해 앉을 수 있도록 했다. | [강의실 책상과 의자](../design/stage1/assets/lecture) · [웹 좌석 정의](../online/campus-seats.js) |
| #25 · 컴퓨터학부 간판 | IT4 정문의 글자가 웹판에서도 LAN판과 같은 자리에 나타난다. | [캠퍼스 장소](../public/campus/scenes.js) · [웹 표시 검사](../online/check-class.mjs) |
| #28 · 의자 선택과 자리 이동 | 강의실 책상과 도서관 탁자 뒤쪽을 눌렀을 때 가까운 의자를 선택하고, 이미 앉은 사람도 다른 빈자리로 옮겨 앉도록 했다. | [좌석 선택과 등받이 표시 검사](../online/check-chair-art.mjs) |
| #29 · 지난 채팅 읽기 | 친구가 메시지를 보내도 읽던 줄을 유지하고, 답장을 보내거나 **최신 대화**를 누르면 마지막 메시지로 돌아간다. | [채팅 입력·스크롤 검사](../online/check-chat-scroll.mjs) |
| #32 · 웹 애니메이션 | 공부를 시작하면 친구에게도 책 읽는 동작이 보인다. 일청담에서 나뭇잎 앞뒤로 걷거나 장난을 할 때 캐릭터와 효과를 그리는 순서를 다듬었다. | [화면 표시 검사](../online/check-world-render.mjs) |
| #33 · 장소 이동 카드 | IT4 정문의 간판, 강의실 책상과 의자, 도서관 공동 테이블을 게임에 놓인 모습으로 카드에 담았다. | [PC·모바일 플레이 화면과 장소 카드](play-screens.md) |

팀은 캠퍼스 지도, 공부 도구, 의상처럼 독립적으로 진행한 작업을 변경 요청 단위로 병합했다. 모바일 화면을 통합한 뒤에도 회전 직후의 입력 오류와 버튼 모서리처럼 범위가 다른 수정을 각각 기록했다. 행사 광장의 100명 지원은 이후 별도의 서버 변경과 측정으로 검증했다.

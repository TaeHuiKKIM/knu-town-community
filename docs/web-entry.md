# 웹에서 모임을 열고 홈 화면에 추가하기

[웹 광장](https://knu-direct-plaza.vercel.app/)의 **초대** 또는 **친구**에서 학과·동아리·스터디 모임을 만든다. 이름과 주제를 정하고 모임 정보를 열어 링크나 QR을 공유한다. 학교·학과·동아리 표시는 선택 사항이다. 모임 이름과 소속은 초대 링크를 받은 사람에게 보인다.

초대를 받은 사람은 방에 참여하기 전에 정보를 읽고 **모임 참여**를 고른다. 모임은 웹 방 한 곳의 정원 4명을 사용한다. 만석이면 대기한 뒤 빈자리에 입장할 수 있다. 모임을 나간 후 초대를 다시 열면 참가 여부를 새로 선택한다. 행사 LAN 메인 광장은 별도로 최대 100명을 수용한다.

Chrome과 호환 브라우저에서는 옷장의 **화면 설정 · 문의 → 홈 화면에 추가** 또는 브라우저 설치 메뉴에서 설치할 수 있다. iPhone Safari에서는 공유 메뉴에서 **홈 화면에 추가**를 선택한다. 설치 아이콘은 기본 광장을 연다. 오프라인 상태에서 웹 광장을 열면 원래 초대 주소를 보존한 재연결 화면이 표시된다.

코드를 새로 받았다면 `online`에서 `npm ci`, `npm run build`, `npm run check:install`을 실행해 설치 가능 조건, 아이콘 크기와 오프라인 복귀를 확인한다. 멀티플레이는 참가자 간 연결이 필요하다.

## 다른 브라우저로 기록과 옷장 옮기기

1. 옷장에서 닉네임·캐릭터·과잠 또는 해금한 코디를 선택하고 **저장**한다.
2. 진행 중인 공부 구간은 내용을 입력해 확인한다. **기록 → 확인 기록 백업**으로 파일을 받는다.
3. 새 브라우저에서 **기록 → LAN·웹 백업 가져오기**를 열고 파일을 고른 뒤 가져올 기록 수를 확인한다. 같은 프로필은 중복 기록 없이 합칠 수 있다. 이미 다른 프로필의 기록이 있으면 빈 브라우저 프로필을 사용한다.
4. 옷장을 열어 닉네임과 착용 코디를, 기록에서 확인 시간과 씨앗 구매 내역을 확인한다. 공부 중인 구간은 백업 파일에 담기지 않는다.

## 친구에게 수업 중 표시하기

IT대학 융복합관(IT5) 앞마당의 **수업 듣기**를 누른다. 같은 방의 친구는 캐릭터 이름표와 친구 목록에서 수업 상태를 보고, 나중에 입장한 사람에게도 상태가 표시된다. 수업을 마치거나 다른 장소로 이동하면 표시가 해제된다. [웹 수업 상태 검사](../online/check-class.mjs)

## 강의실과 도서관에서 자리 고르기

IT대학 융복합관에서 IT4호관으로 이동한 뒤 정문의 **컴퓨터학부** 간판 아래 출입구로 들어간다. 강의실에는 책상 8개와 의자 24개가 있다. 빈 의자나 그 앞쪽 책상을 누르면 캐릭터가 해당 자리로 걸어간다. 행동 버튼에 자리 번호와 **일어나기**가 보이면 앉은 상태다. 휴대폰에서는 이 버튼을, PC에서는 지도에 초점을 두고 스페이스 키를 눌러 일어난다. 웹 방 한 곳에는 네 명이 함께 입장할 수 있다. [장소별 가구와 좌석](../online/campus-seats.js)

도서관 라운지에서는 둥근 탁자 뒤로 보이는 빈 의자도 선택할 수 있다. 앉은 채로 다른 빈자리를 누르면 그 자리로 옮겨 앉는다. [좌석 조작 브라우저 검사](../online/check-chair-art.mjs)

## 휴대폰에서 지난 채팅 읽기

대화 내역을 위로 밀면 읽던 줄을 유지해 친구가 새 메시지를 보내도 앞선 대화를 이어 읽을 수 있다. **최신 대화**를 누르거나 답장을 보내면 맨 아래로 돌아간다. 웹판은 입퇴장 알림을 포함한 최근 25줄, LAN 방의 채팅 창은 최근 메시지 50개를 보여 준다.

PC에서는 Tab으로 대화 내역을 선택한 뒤 방향키로 조금씩 읽거나 Page Up·Page Down으로 한 화면씩 이동한다. Esc를 누르면 지도를 다시 조작할 수 있다. [채팅 조작 브라우저 검사](../online/check-chat-scroll.mjs)

# 웹에서 모임을 열고 홈 화면에 추가하기

[웹 광장](https://knu-direct-plaza.vercel.app/)의 **초대** 또는 **친구**에서 학과·동아리·스터디 모임을 만든다. 이름과 주제를 정하고 모임 정보를 열어 링크나 QR을 공유한다. 학교·학과·동아리 표시는 선택 사항이다. 모임 이름과 소속은 초대 링크를 받은 사람에게 보인다.

초대를 받은 사람은 방에 참여하기 전에 정보를 읽고 **모임 참여**를 고른다. 모임은 웹 방 한 곳의 정원 4명을 사용한다. 만석이면 대기한 뒤 빈자리에 입장할 수 있다. 모임을 나간 후 초대를 다시 열면 참가 여부를 새로 선택한다. 행사 LAN 메인 광장은 별도로 최대 100명을 수용한다.

Chrome과 호환 브라우저에서는 옷장의 **화면 설정 · 문의 → 홈 화면에 추가** 또는 브라우저 설치 메뉴에서 설치할 수 있다. iPhone Safari에서는 공유 메뉴에서 **홈 화면에 추가**를 선택한다. 설치 아이콘은 기본 광장을 연다. 오프라인 상태에서 웹 광장을 열면 원래 초대 주소를 보존한 재연결 화면이 표시된다.

코드를 새로 받았다면 `online`에서 `npm ci`, `npm run build`, `npm run check:install`을 실행해 설치 가능 조건, 아이콘 크기와 오프라인 복귀를 확인한다. 멀티플레이는 참가자 간 연결이 필요하다.
